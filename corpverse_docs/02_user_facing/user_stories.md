# User Stories / Use Cases

Format: As a [role], I want to [action], so that [benefit].

## Job Seeker

- As a job seeker, I want to create a profile with my resume and skills, so that companies can evaluate me for relevant roles.
- As a job seeker, I want to browse companies and roles filtered by domain, so that I only see relevant opportunities.
- As a job seeker, I want to apply to a role and get screened automatically, so that I know quickly whether I'm a fit.
- As a job seeker, I want specific feedback when I'm rejected at screening, so that I know what to improve before reapplying.
- As a job seeker, I want to go through a chat-based interview relevant to my role and resume, so that the experience feels realistic.
- As a job seeker, I want feedback if I fail the interview, so that I can improve for next time.
- As a job seeker, I want to receive and respond to a job offer, so that I can decide whether to accept.

## Employee

- As an employee, I want to see my assigned tasks clearly, so that I know what to work on.
- As an employee, I want to earn EXP for completed tasks, so that I can track my progress toward promotion.
- As an employee, I want to know how close I am to a promotion, so that the growth path feels transparent.
- As an employee, I want to resign from my job, so that I can pursue another offer or start my own company.
- As an employee, I want to receive an exit interview / feedback if I leave or am let go, so that the experience feels complete rather than abrupt.

## Founder

- As a founder, I want to create a company with a name, domain, and initial roles, so that I can start hiring.
- As a founder, I want to post job roles that other players can apply to, so that my company can grow.
- As a founder, I want candidates to be automatically screened and interviewed using the platform's pipeline, so that I don't have to manually evaluate every applicant.
- As a founder, I want my company to be staffed even if no real players apply right away, so that it doesn't feel broken or empty.
- As a founder, I want to manage my employees (assign tasks, promote, or let go), so that I can run my company realistically.

## System / Admin (supporting)

- As the platform, I want 5 seed companies pre-populated at launch, so that new users always have somewhere to apply on day one.
- As the platform, I want a shared feedback-generation module, so that rejection, termination, and exit feedback are all consistent in tone and structure.
